# bibliotheque-libre-data-en

Textes (en) de [Bibliothèque libre](https://github.com/salimadour31-boop/bibliotheque-libre), servis par GitHub Pages :
`https://salimadour31-boop.github.io/bibliotheque-libre-data-en/books/<id>.txt`

- Uniquement des œuvres du **domaine public** (auteurs morts au plus tard en 1955) ou sous licence libre.
- Chaque fichier conserve en tête sa source et sa licence (en-tête et licence Project Gutenberg conservés intégralement ; transcriptions Wikisource sous CC BY-SA 4.0).
- Liste complète avec liens d'origine : `SOURCES-en.csv` dans le dépôt principal.
- Textes en UTF-8, normalisés NFC. Les fichiers `meta*.json` sont des index techniques générés par les scripts.
